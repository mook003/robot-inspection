# robot-accuracy docs

Documentation site for [robot-inspection](https://github.com/mook003/robot-inspection), built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Local Development

```bash
pip install mkdocs-material
mkdocs serve
```

Open `http://127.0.0.1:8000`.

## Deploy

Automatically deployed to GitHub Pages on every push to `main` via GitHub Actions.

Manual deploy:
```bash
mkdocs gh-deploy
```
